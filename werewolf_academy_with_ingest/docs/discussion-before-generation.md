# 先討論、後生成｜決策紀錄

**2026-11-21 作業設計決策**

| 問題 | 決策 | 理由 |
|---|---|---|
| 應該教整套狼人殺嗎？ | 不。以 12 人狼王守衛板為主要教學版本。 | 教材更精準，減少不同房規的衝突。 |
| Wiki 要只收角色介紹嗎？ | 不。包含角色、流程、勝負、交互結算、版本比較。 | 五篇以上資料可以形成互補的教學內容。 |
| 為什麼要對來源加 Scope？ | 來源可能來自不同遊戲引擎與桌遊系列。 | 不能因為文字相似就採用同一規則。 |
| 互動何者最有教學價值？ | 翻角色卡、夜間結算、知識測驗。 | 能從認識 → 操作 → 檢驗理解建立學習流程。 |
| Graph 要怎樣才能被驗證？ | 儲存每次節點結果、來源 ID、初次錯誤和修復紀錄。 | 課程評分重視實際執行與反思，不是只有流程圖。 |
| 如何做反思？ | 同資料比較 V1（後檢查）與 V2（前檢查）。 | 能具體指出版本檢查前移的作用。 |
